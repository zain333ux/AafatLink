# Phase 1 demonstration

1. Run `.\mvnw.cmd javafx:run`.
2. Confirm the login view says **Demonstration mode** and that the real sign-in controls are disabled.
3. Select Requester, Volunteer, Coordinator or Administrator under **Preview as role**.
4. Open the demonstration workspace.
5. Confirm the sidebar changes for the selected role.
6. Select navigation items to show the documented implementation-phase message.
7. Sign out and confirm the session returns to login.

All Phase 1 names, role sessions and dashboard figures are demonstration data. They are not Supabase accounts or live operational records.
